Tarea 1.1

Terminología y conceptos básicos de la IA

El examen prueba que sepas distinguir estos términos entre sí — muchas preguntas son "¿cuál de estos describe mejor X?".

Glosario esencial (en lenguaje simple)

IA (Inteligencia Artificial)

Campo amplio de la informática enfocado en crear sistemas que realicen tareas que normalmente requieren inteligencia humana.

ML (Machine Learning)

Subcampo de la IA donde el sistema aprende patrones de los datos, en lugar de seguir reglas programadas explícitamente.

Aprendizaje profundo (Deep Learning)

Subcampo del ML que usa redes neuronales con múltiples capas para aprender representaciones complejas.

Redes neuronales

Modelos computacionales inspirados en el cerebro, compuestos de capas de nodos interconectados.

Visión artificial

Campo de la IA que permite a las máquinas interpretar imágenes o video.

NLP (Procesamiento de Lenguaje Natural)

Campo de la IA enfocado en que las máquinas entiendan y generen lenguaje humano.

Modelo

La representación matemática ya entrenada que hace predicciones o genera resultados.

Algoritmo

El procedimiento matemático usado para entrenar un modelo a partir de datos.

Entrenamiento (training)

Proceso de "enseñar" a un modelo usando datos históricos.

Inferencia

Usar un modelo ya entrenado para hacer predicciones sobre datos nuevos.

Sesgo (bias)

Cuando un modelo produce resultados sistemáticamente injustos o inexactos, por datos o diseño sesgado.

Equidad (fairness)

Principio de que los resultados de un modelo no discriminen injustamente a ciertos grupos.

Adecuación (fit)

Qué tan bien un modelo se ajusta a los datos — ni underfitting (muy simple) ni overfitting (memoriza en vez de aprender).

LLM (Large Language Model)

Modelo entrenado con enormes cantidades de texto para entender y generar lenguaje.

GenAI (IA Generativa)

IA capaz de generar contenido nuevo (texto, imágenes, audio, código) similar a los datos con los que fue entrenada.

IA agéntica (Agentic AI)

Sistemas de IA que actúan de forma autónoma, tomando decisiones y ejecutando tareas de varios pasos para lograr un objetivo.

Cómo se relacionan: IA, ML, Deep Learning, GenAI y IA agéntica

Inteligencia Artificial (IA)
El campo más amplio: cualquier sistema que "actúe de forma inteligente"
Machine Learning (ML)
Sistemas que aprenden patrones de datos
Deep Learning
ML con redes neuronales de múltiples capas
GenAI / LLMs
Genera contenido nuevo
IA agénticaNo es una capa más adentro — es una CAPACIDAD que se construye usando LLMs/GenAI para planificar y ejecutar tareas de forma autónoma.
🇪🇸 Es como muñecas rusas: la IA es la muñeca grande, el ML está dentro, el Deep Learning más adentro, y GenAI es la muñeca más pequeña. La IA agéntica es como darle piernas a la muñeca más pequeña para que camine sola.
Trampa de examen: no toda IA es ML (hay sistemas basados en reglas que son IA pero no aprenden de datos), y no todo ML es Deep Learning (regresión lineal es ML pero no usa redes neuronales).

Tipos de inferencia

Tipo Cómo funciona Ejemplo
Por lotes (batch) Procesa grandes volúmenes de datos de una sola vez, sin necesidad de respuesta inmediata Generar reportes nocturnos de todos los clientes
Tiempo real Responde de inmediato a una sola solicitud Un chatbot respondiendo una pregunta
Asincrónica La solicitud se encola y se procesa cuando hay capacidad; la respuesta llega después Analizar un video largo subido por el usuario
Sin servidor (serverless) La infraestructura se administra automáticamente y escala a cero cuando no hay uso Una API de inferencia que solo se activa cuando llega una solicitud

Tipos de datos en modelos de IA

Según etiquetas

Etiquetados vs sin etiquetar

Etiquetados = ya tienen la respuesta correcta asociada; sin etiquetar = solo datos crudos.

Formato

Tabulares

Datos organizados en filas y columnas, como una hoja de cálculo.

Formato

Series temporales

Datos capturados en secuencia a lo largo del tiempo (ej. ventas mensuales).

Formato

Imágenes

Datos visuales usados en visión artificial.

Formato

Texto

Datos de lenguaje usados en NLP y LLMs.

Organización

Estructurados vs no estructurados

Estructurados = con esquema fijo (bases de datos); no estructurados = sin formato fijo (texto libre, imágenes, audio).

Tipos de aprendizaje de IA/ML

Supervisado

Aprendizaje supervisado

Se entrena con datos ya etiquetados (entrada + respuesta correcta conocida).

Ej: clasificar correos como spam o no spam
No supervisado

Aprendizaje no supervisado

Se entrena con datos sin etiquetar; el modelo encuentra patrones o agrupaciones por sí mismo.

Ej: segmentar clientes por comportamiento de compra
Refuerzo

Aprendizaje por refuerzo

El modelo aprende por prueba y error, recibiendo recompensas o penalizaciones según sus acciones.

Ej: un agente que aprende a jugar un videojuego
Tarea 1.2

Casos de uso prácticos de la IA

El examen prueba tu criterio de negocio: saber cuándo SÍ conviene usar IA, cuándo NO, y qué técnica o servicio elegir.

¿Cuándo la IA aporta valor y cuándo no es apropiada?

Sí aporta valor

Usar IA/ML cuando...

  • Se necesita ayudar a las personas a tomar decisiones
  • Se busca escalar una solución a gran volumen
  • Se quiere automatizar tareas repetitivas
No es apropiada

Evitar IA/ML cuando...

  • El costo de implementarla supera el beneficio (análisis costo-beneficio negativo)
  • Se necesita un resultado exacto y determinístico, no una predicción probabilística
🇪🇸 No uses un modelo predictivo para calcular el IVA de una factura: eso es una fórmula exacta, no una predicción.

ML tradicional vs Modelos Fundacionales (FM)

Usa ML tradicional cuando...

Modelo entrenado a la medida

  • Hay requisitos de explicabilidad regulatoria
  • La tarea es muy específica y bien definida
  • Existen restricciones operativas estrictas (costo/latencia)
Usa un Foundation Model cuando...

Modelo preentrenado de propósito general

  • La tarea es generativa o de lenguaje/imagen general
  • Se quiere velocidad de desarrollo (sin entrenar desde cero)
  • El caso de uso se beneficia de conocimiento general amplio
Trampa de examen: si el escenario menciona "cumplimiento regulatorio" o "explicar exactamente por qué el modelo decidió X" → apunta a ML tradicional, no a un FM.

Fuentes de modelos fundacionales (FM)

Opción 1

Modelos preentrenados de código abierto

Ya vienen entrenados por un tercero; se usan directamente o se ajustan (fine-tuning).

Opción 2

Modelos personalizados de entrenamiento

Se entrenan desde cero o se ajustan con datos propios de la organización.

Métodos para usar un modelo en producción

Opción 1

Servicio de API administrado

  • AWS gestiona la infraestructura por ti
  • Solo llamas al modelo vía API (ej. Amazon Bedrock)
  • Menor esfuerzo operativo
Opción 2

API autoalojada

  • Tú despliegas y administras el modelo (ej. en un endpoint de SageMaker)
  • Más control sobre configuración e infraestructura
  • Mayor responsabilidad operativa

Métricas para evaluar modelos

Métricas de rendimiento del modelo
  • Exactitud (accuracy): % total de predicciones correctas
  • Precisión (precision): de lo que el modelo dijo positivo, cuánto acertó
  • Exhaustividad (recall): de todos los positivos reales, cuántos detectó el modelo
  • F1 Score: equilibrio entre precisión y exhaustividad
Métricas de negocio
  • Costo por usuario
  • Costos de desarrollo
  • Opinión de los clientes
  • ROI (retorno de la inversión)
Trampa de examen: "precisión" y "exactitud" NO son sinónimos en el examen. Precisión = de tus predicciones positivas, cuántas fueron correctas. Exactitud = de todas tus predicciones (positivas y negativas), cuántas fueron correctas.
Recuerdo activo

Ponte a prueba (sin ver la respuesta primero)

Responde mentalmente antes de abrir cada tarjeta.
¿Todo modelo de Machine Learning usa redes neuronales?
No. Deep Learning es el subcampo de ML que usa redes neuronales de múltiples capas, pero hay modelos de ML (como regresión lineal) que no las usan.
Un banco necesita calcular el interés exacto de un préstamo según una fórmula fija. ¿Debería usar un modelo de IA/ML?
No. Se necesita un resultado exacto y determinístico, no una predicción — la IA/ML no es apropiada aquí.
Una empresa quiere agrupar a sus clientes por comportamiento de compra, sin tener categorías previas definidas. ¿Qué técnica de ML aplica?
Clustering (agrupación) — es aprendizaje no supervisado, ya que no hay etiquetas previas.
¿Qué servicio de AWS usarías para convertir un archivo de audio en texto?
Amazon Transcribe.
Un caso de uso requiere explicabilidad regulatoria estricta sobre por qué el modelo tomó cada decisión. ¿ML tradicional o Foundation Model?
ML tradicional — los FMs son más difíciles de explicar decisión por decisión.
¿Cuál es la diferencia entre precisión (precision) y exactitud (accuracy)?
Precisión mide qué tan correctas fueron las predicciones POSITIVAS; exactitud mide el porcentaje total de predicciones correctas (positivas y negativas).
Una aplicación necesita responder de inmediato a cada solicitud individual del usuario. ¿Qué tipo de inferencia es?
Inferencia en tiempo real.
¿Qué diferencia hay entre usar un servicio de API administrado y una API autoalojada para poner un modelo en producción?
El servicio de API administrado (ej. Amazon Bedrock) es gestionado por AWS; la API autoalojada requiere que tú despliegues y administres la infraestructura (ej. SageMaker endpoints).
Resumen mental final

IA es el concepto más amplio. ML aprende de datos. Deep Learning usa redes neuronales. GenAI crea contenido nuevo. IA agéntica actúa de forma autónoma. El examen premia que sepas identificar cuál capa aplica a cada escenario — y que sepas elegir el servicio de AWS correcto para cada etapa del pipeline.
